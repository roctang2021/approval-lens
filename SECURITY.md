# Reporting security issues

For vulnerabilities, use GitHub's
[private vulnerability reporting](https://github.com/roctang2021/approval-lens/security/advisories/new).
Include the affected version, expected behavior and a minimal reproduction
with placeholder data. Do not include real API keys or other secrets.

Reports are reviewed by the project maintainer. There is no guaranteed response
time. Fixes are developed against the current version on `main`; older versions
do not have separate support branches.

Use [public issues](https://github.com/roctang2021/approval-lens/issues) for
ordinary bugs that do not reveal a vulnerability or private information.
